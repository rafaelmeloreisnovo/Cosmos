# Linguagem e Semântica — Adaptador do Codec Parabólico

**Protocolo:** `RAFAELIA-PSC-1`  
**Função deste arquivo:** adaptar o método ao mapa do Cosmos sem gerar evidência cosmológica nova.

## 1. Relação multiescala

O codec organiza relações declaradas em diferentes níveis:

```text
glifo -> token -> frase -> bloco -> sessão -> repositório -> ecossistema
```

Essa estrutura é análoga a uma leitura multiescala, mas não implica que a dinâmica linguística seja fisicamente idêntica a sistemas cosmológicos.

## 2. Uso permitido

- catalogar símbolos e contextos;
- preservar proveniência e estado epistemológico;
- comparar relações entre escalas documentais;
- gerar perguntas para análise de redes;
- registrar `TOKEN_VAZIO` e contradições.

## 3. Uso não permitido

```text
padrão textual -> prova de lei cosmológica
espiral narrativa -> evidência de galáxia
fractal simbólico -> dimensão física medida
glifo Ω -> parâmetro cosmológico
frequência declarada -> radiação observada
```

Essas ligações exigem modelo dimensional, dados observacionais, baseline, likelihood e falsificador próprios.

## 4. Sete leituras no domínio

| Leitura | Pergunta válida |
|---|---|
| direta | qual sequência de claims foi registrada? |
| reversa | quais fontes sustentam o resultado? |
| antiderivada temporal | como as evidências se acumularam? |
| derivada local | em qual revisão o claim mudou? |
| contrafactual | qual dado derrubaria a interpretação? |
| inversão de papéis | o que modelo, observador e instrumento registram? |
| multiescala | a relação permanece do dado ao catálogo? |

## 5. Relação com RLL

O RLL permanece responsável por modelos, datasets, priors, likelihoods e comparação cosmológica. Este adaptador pode apontar para claims do RLL, mas não promovê-los.

```text
semantic_similarity NOT_EVIDENCE_FOR cosmological_identity
```
