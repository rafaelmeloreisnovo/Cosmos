# Cânones do Cosmos RAFAELIA

Este diretório reúne documentos que definem a linguagem, as invariantes, os contratos epistêmicos e os limites formais do repositório `Cosmos`.

## Documento fundador

- [`01_CANONE_DO_COSMOS_RAFAELIA.md`](01_CANONE_DO_COSMOS_RAFAELIA.md) — do `∅ observado` à recorrência em sete dimensões; formaliza as classes `[E]`, `[C]`, `[H]` e `[P]`, as 42 hiperformas, o operador relacional, BITRAF64, a separação ZIPRAF entre dados e selo e o ciclo `VAZIO → VERBO → CHEIO → RETROALIMENTAÇÃO → NOVO VAZIO`.

## Regra de leitura

```text
[E] resultado exato/verificável
[C] convenção interna declarada
[H] hipótese testável e falsificável
[P] parábola ou linguagem simbólica
```

Nenhum documento canônico deve converter uma dessas classes em outra sem registrar evidência, método e revisão.

## Regra do vazio

`TOKEN_VAZIO` preserva explicitamente uma ausência, variável desconhecida ou estado ainda não medido. Ele não deve ser preenchido por inferência silenciosa.

## Regra de evolução

Cada revisão deve registrar:

```text
F_ok   → o que permanece sustentado
F_gap  → o que continua ausente, contraditório ou não validado
F_next → o próximo teste, cálculo ou implementação
```
