# RAFAELIA COSMOS REGIME INDEX

> Índice de regimes para o repositório `Cosmos`, separando semente simbólica, hipótese, fórmula, metáfora visual e possível validação futura.

## Função do repositório

`Cosmos` é tratado como camada seminal do ecossistema RAFAELIA/RLL.

```text
Cosmos = semente conceitual + operadores simbólicos + hipóteses geométricas + linguagem de origem.
```

Este repositório não deve ser usado como prova física final sem passagem por formalização, dado, métrica e validação reprodutível.

---

## Regimes principais

| Regime | Descrição | Uso correto |
|---|---|---|
| `[SEMENTE]` | intuição, metáfora, imagem, operador simbólico | gerar hipóteses |
| `[HIPÓTESE]` | afirmação que pode virar teste | converter em variável observável |
| `[FÓRMULA-AUTORAL]` | expressão matemática ainda não validada externamente | registrar, normalizar e migrar para RLL se útil |
| `[VISUAL-SIMBÓLICO]` | leitura de galáxias, espirais, Fibonacci e imagens | não declarar como evidência estatística sem análise |
| `[MODELO-CANDIDATO]` | bloco que já tem variáveis e dinâmica mínima | enviar para RLL para validação |
| `[LIMITE]` | alerta contra prova indevida | manter sempre visível |

## Regra de promoção para RLL

Um bloco do `Cosmos` só deve migrar para o núcleo científico do RLL se passar por:

```text
1. definição clara;
2. variáveis explícitas;
3. unidade ou adimensionalidade;
4. domínio de validade;
5. hipótese falsificável;
6. dado ou simulação;
7. métrica;
8. baseline;
9. incerteza;
10. limite de claim.
```
