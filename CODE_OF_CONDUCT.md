# Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of background, identity, or level of experience.

## Standards

- Cite all scientific sources properly
- Respect diverse cultural and philosophical perspectives
- Distinguish between scientific claims and symbolic interpretations
- Gracefully accept constructive feedback
